## 📌 Project Overview

Employee attrition is a major challenge for organizations as it leads to increased recruitment costs, reduced productivity, and loss of experienced employees.

This project develops an **Employee Attrition Prediction and Recommendation System** using the **IBM HR Analytics Employee Attrition Dataset**. Machine Learning models are used to predict employee attrition, while an interactive **Power BI Dashboard** provides business insights for HR professionals.

The project combines:

- 📊 Exploratory Data Analysis (EDA)
- 🤖 Machine Learning
- 📈 Data Visualization
- 📉 Predictive Analytics
- 📋 Business Intelligence Dashboard
